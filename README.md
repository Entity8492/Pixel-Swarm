# Pixel Swarm - Privacy Policy

This repository hosts the privacy policy for **Pixel Swarm**, a pixel-art survival game with up to 8-player co-op.

**Read the policy:** https://YOUR-GITHUB-NAME.github.io/pixel-swarm-privacy/

**Get the game:** https://zenerationzero.itch.io/pixel-swarm

## In short

- Pixel Swarm does not collect, store or sell any personal information.
- There are no accounts, ads, analytics or tracking.
- Your progress and settings are saved only on your own device.
- Online co-op is optional. It connects players' devices directly, using the PeerJS connection service to set up the connection.

The full policy is in [`index.html`](index.html), which is published with GitHub Pages.
